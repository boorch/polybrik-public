# Edits to core/ for the SDL port

One entry per edited `core/` file or group of files, under the port's own patch numbers. The firmware is vendored from polyend/tracker-ce at commit `7fd6c2c`. Hunk positions, where listed, come from `git diff -U0` against the upstream file.

Most edits are guarded with `PLATFORM_SDL`. A few are unguarded because the new code is correct on every target (noted as "none" in the Guard line).

## core/source/mtStructs.h (patch 15)
- Hunks: `@@ -596,0 +597,22 @@` (new `SamplePtr` before `strInstrument`), `@@ -605,0 +628,3 @@`, `@@ -606,0 +632 @@` (the field). The upstream `static_assert(sizeof(strInstrument) == 372)` is back unchanged on every platform.
- Change: under `PLATFORM_SDL`, `strInstrument::strSampleBankSlot::address` is a `SamplePtr` instead of `int16_t*`. `SamplePtr` is `{ uint32_t off; }`, the byte offset from `externalRamSampleMemory` plus 1, with 0 meaning nullptr (so zeroed memory reads as nullptr, as a zeroed pointer does on the device). Members: defaulted default constructor (keeps `strInstrument` trivial for its `memcpy`/`memset` users), `constexpr SamplePtr(nullptr_t)` (keeps `defaultInstrumentParams` constant-initialised), implicit `SamplePtr(int16_t*)`, implicit `operator int16_t*()`, and `explicit operator uint8_t*()`.
